# Obstacle Dodge

Arcade game for GNU Octave 11.3.0, made for the UE TechnEx coding project (M1 Neurosciences, Lyon 1, Fall 2026).

Collect stars, dodge asteroids and reach the target score before losing your 3 lives.

## How to run
1. Open GNU Octave and go to the folder containing `obstacle_dodge_VF.m`.
2. Type `obstacle_dodge_VF` in the Command Window.
3. Click the game window, then press SPACE to start.

## Controls
LEFT / RIGHT arrows or A / D to move, P to pause, R to replay, M to switch the sound on or off, Q to quit.
